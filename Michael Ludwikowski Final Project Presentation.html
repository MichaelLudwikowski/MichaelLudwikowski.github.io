The Problem

  • New traders enter the market without practical experience
  • Most lose money due to poor risk understanding
  • Existing tools are too advanced or too simplified
  • No safe environment to learn before risking real money

Project Goals

  • Simulate real trading with fake money
  • Provide AI-generated buy, sell, or hold recommendations
  • Display charts, portfolio data, and gain/loss feedback
  • Offer practice and simulation modes for guided learning
  • Store all user activity persistently

System Architecture

  • Flask web app - routes, sessions, multi-page UI
  • SQLite database - users, accounts, holdings, transactions
  • Bokeh - interactive stock charts
  • Ollama - LLM based predictions + fallback

Core Feature: Trading

  • Register and log in with a personal account
  • Start with $1,000 in simulated funds
  • Search stocks by symbol
  • Buy and sell shares through the web interface
  • Portfolio and balance update immediately after each trade

Core Feature: AI Recommendations

  • Powered by Llama model 3.2 running locally
  • Returns BUY / SELL / HOLD with confidence and risk level
  • Includes a short rationale for the recommendation
  • Available on every stock detail page

Practice and Simulation Modes

  • Practice Mode - synthetic companies, news events, difficulty levels
  • Simulation Mode - replay real historical market data over time
  • Both modes are isolated from the main trading account
  • Designed for learning without affecting real portfolio state

Challenges Overcome

  • API rate limits - caching and fallback behavior added
  • AI availability - rule-based fallback keeps app running
  • Full-stack integration - connected data, AI, trading, and UI into one system
  • Scope management - prioritized core flows over unfinished features

Future Enhancements

  • Complete multi-account workflow for the main UI
  • Improve AI performance tracking and reporting
  • Add expanded educational tools (alerts, quizzes, learning modules)
  • Stronger account security and portfolio analytics
  • Load times for pages / preloading pages & AI recommendations.

Summary

  • Functional educational trading platform in Python + Flask
  • Integrated real market data, AI analysis, and persistent storage
  • Covered practice and simulation modes for beginner learning
